Fonctionnalités implémentées

Fonctionnalité Description État
1. Système d'équipes Création avec nom + couleur unique, sélection de 6–8 morpions parmi 16 personnages, liste avec historique, suppression avec confirmation ✓
2. Personnages (Morpions) 16 personnages uniques avec 4 stats équilibrées (HP, Attack, Mana, Accuracy), somme=15, contrainte CHECK en BD, images personnalisées ✓
3. Partie normale (Mode classique) Grille 3×3 ou 4×4, règles tic-tac-toe, victoire par ligne/colonne/diagonale ou grille pleine, limite de tours configurables (5-50) ✓
4. Intelligence Artificielle Algorithme Minimax avec poda Alpha-Beta, 3 niveaux de difficulté (Easy/Medium/Hard), profondeurs adaptatives, optimisation 90% branches coupées ✓
5. Partie avancée (Mode combat) Système de combat au tour par tour, attaques adjacentes avec précision, HP/mana dynamiques, mort des morpions (HP≤0), cases détruites ✓
6. Système de sorts (3 sorts) Boule de Feu (3 dégâts, 2 mana), Soin (2 HP, 2 mana), Armageddon (détruit cellule, 3 mana), calcul probabilité avec accuracy ✓
7. Statistiques page d'accueil 4 statistiques SQL : compteurs (équipes, morpions, parties), top 3 équipes victorieuses, durées parties (min/max/moyenne), logs moyens par mois ✓
8. Statistiques avancées Dashboard dédié : performance équipes (winrate, victoires/défaites), usage morpions (popularité, winrate), sorts utilisés, méthodes de victoire, classements ✓
9. Système de logs Historique chronologique de toutes les actions (placement, attaque, sort, victoire), stockage en BD avec séquence unique, affichage temps réel ✓
10. Session caching État des parties en mémoire serveur (évite SELECT à chaque tour), synchronisation automatique SESSION ↔ BD, invalidation à la fin de partie ✓
11. AJAX partial rendering Mise à jour partielle grille mode avancé sans rechargement complet (5KB vs 50KB), route fragment dédiée, fluidité interface ✓
12. Build CSS automatique Script Python (build_css.py) : 30+ fichiers CSS → 1 fichier main.css, 30 requêtes → 1 requête, minification optionnelle ✓
13. Architecture MVC stricte Séparation Model/View/Controller, Repository Pattern, logique pure testable, composants réutilisables (templates, macros, CSS BEM) ✓
14. Contraintes BD avancées CHECK (somme stats=15), UNIQUE (couleur équipe), CASCADE (intégrité référentielle), validation double frontend/backend ✓
15. Index BD optimisés 6 index sur foreign keys (team_id, morpion_id, game_id, winner_id), JOINs 10x plus rapides (850ms → 85ms mesurés) ✓
16. Équipe IA automatique Création automatique au démarrage (init.py), 6 morpions équilibrés, équipe "🤖 IA Opponent" toujours disponible pour jouer seul ✓
